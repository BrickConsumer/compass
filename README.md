# Compass

Track almost everything. Your streaks drive a boat on an ocean: a stormy sea when you start, calm golden water when you keep going.

## Prototypes

- `compass-intro.html`: the compass logo forming (ring draws, ticks fade in, needle swings and settles).
- `compass-boat.html`: Three.js front-view boat and ocean, driven by a streak slider.

Open either file through a local server, for example `python3 -m http.server`, then visit the page. `compass-boat.html` loads Three.js from a CDN.
